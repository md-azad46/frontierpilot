Getting Started

FrontierPilot helps you discover research papers from arXiv and provides AI-powered insights.

Prerequisites

  • Python 3.8 or higher
  • Modern web browser (Chrome, Firefox, Edge)
  • Internet connection

Installation

git clone https://github.com/md-azad46/frontierpilot.git
cd frontierpilot
pip install flask flask-cors
python backend.py

How to Search Papers

Step 1: Enter Topic

Type your research topic in the search box (e.g., "large language model", "quantum computing")

Step 2: Select Number of Papers

Use the slider to choose between 5-50 papers

Step 3: Click Search

Click the "Start Research" button to fetch papers from arXiv

Tip: Use specific keywords for better results!

Exporting Results

You can export papers in three formats:

  • JSON - For developers and data analysis
  • CSV - For spreadsheets and databases
  • TXT - For plain text reading

Click the respective button in the results header to download.

Using Dashboard

The Dashboard provides advanced analytics:

  • Top Researchers - Most active authors in your field
  • Communities - Reddit, Discord, and conferences to join
  • Learning Path - Structured roadmap from beginner to advanced

API Reference

Search Endpoint

POST /search
Content-Type: application/json

{
    "topic": "machine learning",
    "max_results": 10
}

Response Format

{
    "papers": [...],
    "count": 10,
    "topic": "machine learning",
    "search_time": "2026-04-26 15:30:00"
}

FAQ

Is FrontierPilot free?

Yes, completely free and open source!

How current are the papers?

FrontierPilot fetches latest papers from arXiv in real-time.

Can I use it offline?

No, internet connection is required to fetch papers from arXiv.

What if I get an error?

Make sure python backend.py is running on port 5000 and Gateway is active.
